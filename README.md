# Accuride Todo App

## Tech Stack
- Next.js
- Hygraph 


## Getting Started

### 1. Clone the repo
git clone https://github.com/ajmal-rizwan/accuride-todo-challenge.git
cd accuride-todo-challenge

### 2. Install dependencies
npm install

### 3. Environment variables
Create a .env.local file:

HYGRAPH_URL=
HYGRAPH_TOKEN=

### 4. Run
```bash
npm run dev
# or
yarn dev

Open http://localhost:3000
